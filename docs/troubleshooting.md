# Диагностика

| Симптом | Вероятная причина | Что проверить |
|---|---|---|
| `Ошибка конфигурации: Не задана ...` | не заполнен `.env` | все четыре обязательные переменные |
| `OAuth GigaChat вернул HTTP 401` | неверный или отозванный `GIGACHAT_AUTH_KEY` | ключ без `Basic ` и кавычек; получить новый в Studio |
| `OAuth GigaChat вернул HTTP 403` | scope не соответствует аккаунту | `GIGACHAT_SCOPE`: `PERS`, `B2B` или `CORP` |
| `GigaChat API вернул HTTP 429` | превышен лимит запросов | подождать; уменьшить `BOT_WORKERS` |
| `GigaChat API вернул HTTP 422` | слишком длинный контекст | уменьшить `MAX_HISTORY_MESSAGES`; бот сам сокращает историю один раз |
| `CERTIFICATE_VERIFY_FAILED` | нет доверия к сертификату | установить сертификаты или задать `GIGACHAT_CA_BUNDLE` |
| VK: ошибка 5 | неверный или просроченный `VK_TOKEN` | создать новый ключ доступа |
| VK: ошибка 15 или 27 | у ключа нет нужных прав | право «Сообщения сообщества» (`messages`) |
| VK: ошибка 100 | неверный `VK_GROUP_ID` или `peer_id` | числовой ID без минуса, то же сообщество |
| VK: ошибка 901 | пользователь запретил сообщения | ограничение пользователя, обойти нельзя |
| Long Poll подключается, но событий нет | не включён Long Poll или тип события | Long Poll API → Включено; событие `message_new` |
| Бот не отвечает в сообщениях сообщества | выключены сообщения сообщества | **Управление** → **Сообщения** |
| Бот не отвечает в беседе | бот не добавлен или запрещено добавление | настройки бота в сообществе |
| Бот отвечает дважды | повторная доставка события | перезапустить бота; встроена защита от дублей |
| `Не удалось прочитать базу знаний` | нет `data/knowledge_base.md` | файл на месте, кодировка UTF-8 |
| `ModuleNotFoundError: vk_gigachat_bot` | не задан путь к пакету | запускать через `scripts/start.*` или `PYTHONPATH=src` |

Если ошибка не подходит под таблицу, смотрите полный лог:

```bash
journalctl -u vk-gigachat-bot -f     # Linux
type logs\bot.log                    # Windows
```

## Отладка

- `LOG_LEVEL=DEBUG` — подробные сообщения, включая пропущенные дубли и статус «печатает».
- Логи не содержат ключей: `Config` исключает секреты из `repr`, а клиент
  GigaChat не печатает токен.
