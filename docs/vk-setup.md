# Настройка сообщества ВКонтакте

Чтобы бот получал сообщения, нужны три вещи: ключ доступа, включённые сообщения
сообщества и включённый Bots Long Poll API.

## 1. Создайте ключ доступа

1. Откройте сообщество под аккаунтом администратора.
2. Перейдите: **Управление** → **Дополнительно** → **Работа с API**.
3. Откройте вкладку **Ключи доступа**.
4. Нажмите **Создать ключ**.
5. Отметьте право **«Сообщения сообщества»** (scope `messages`).
6. Скопируйте ключ — он показывается один раз.

Для работы бота не нужны права на управление сообществом, публикацию на стену
или доступ к фотографиям. Достаточно права на сообщения.

```dotenv
VK_TOKEN=сюда_вставить_ключ_доступа_сообщества
```

## 2. Укажите ID сообщества

`VK_GROUP_ID` — **числовой ID без минуса**, например `123456789`
(не `-123456789` и не короткое имя `my_community`).

Где посмотреть:

- в адресе страницы управления сообществом;
- в разделе **Управление** → **Настройки** → **Адрес сообщества**;
- через VK API `groups.getById`.

```dotenv
VK_GROUP_ID=123456789
```

> Токен и ID должны относиться к одному сообществу. Иначе Long Poll подключится
> не к тому сообществу или VK вернёт ошибку доступа.

## 3. Включите сообщения сообщества

**Управление** → **Сообщения** → включите приём сообщений сообщества.

Если бот должен работать в беседах, в **Настройках для бота** включите
возможность добавления бота в беседы.

## 4. Включите Bots Long Poll API

**Управление** → **Дополнительно** → **Работа с API** → **Long Poll API** →
**Включено**.

В блоке **Bots Long Poll API** → **Типы событий** отметьте:

- **Входящее сообщение** (`message_new`).

Этого достаточно: события стены и комментариев бот не обрабатывает.

## 5. Перезапустите бота

После изменения настроек подождите несколько секунд и перезапустите процесс.

## Проверка

1. Напишите сообществу с другого аккаунта.
2. Убедитесь, что ответ пришёл в тот же диалог.
3. Проверьте команды `/start`, `/help`, `/reset`.
4. Задайте вопрос по курсам и проверьте, что ответ опирается на базу знаний.

## Права и ошибки

| Код / симптом | Причина |
|---|---|
| ошибка 5 | неверный или просроченный `VK_TOKEN` |
| ошибка 15 или 27 | у ключа нет права «Сообщения сообщества» |
| ошибка 100 | неверный `VK_GROUP_ID` или `peer_id` |
| ошибка 901 | пользователь запретил сообщения — это его настройка |
| Long Poll подключается, событий нет | выключен Long Poll или тип события `message_new` |
