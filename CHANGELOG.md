# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-14

### Добавлено

- Бот сообщества ВКонтакте на Bots Long Poll API: ответы в личных сообщениях и беседах.
- Интеграция с GigaChat API: OAuth-токен, автоматическое обновление, повторные попытки.
- Персона «Алина» и база знаний о курсах Зерокодер в `data/knowledge_base.md`.
- Команды `/start`, `/reset`, `/help` и приветствие на естественном языке.
- История диалога по каждому `peer_id`, параллельная обработка разных диалогов.
- Защита от повторной обработки событий Long Poll.
- Разбиение длинных ответов под лимит сообщения VK и очистка Markdown.
- Логирование в консоль и в `logs/bot.log` с ротацией.
- Скрипты запуска для Windows и Linux/macOS.
- Документация: архитектура, настройка GigaChat и VK, деплой, диагностика, безопасность.
- Тесты на конфигурацию, промпт и обработку текста, CI на GitHub Actions.
